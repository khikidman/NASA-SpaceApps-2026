# Living Diorama implementation contract

The user selected direction A with simplified UI, high-priority facts, clear
resources and creative, graphical minigames. The earlier optional-only learning
hierarchy is superseded.

Implement a wide experiment scene inside the existing mission dialog. Use a
promoted lunar-stage illustration with separate native vector objects, hit areas,
mechanical motion, signal/flow paths and optional cutaway inspection. The backdrop
contains no controls, scientific labels, inventory or success states. The scene
is an interactive authored model; it does not become a second campaign engine.

Preserve the five ordered tasks, seeded proof, free drafts, standard/boost
tradeoff, exercise, world/base transitions and accepted-action replay. Main
learning appears above the scene. Detailed science and source notes remain
optional. No real instrument readings or water-safety simulation are claimed.

Supplies use visible names and amount/capacity, plus a separate token bank.
Forecast only resources changed by the selected action: current → after, actual
capped gain, and separate signed use/get values. Research tokens are spendable;
research progress is permanent. No duplicated permanent HUD inside the activity.

Graphical interactions keep keyboard activation, large touch targets, clear
selected/done shapes, gentle mistakes and resettable practice. A see-inside lens
reveals the authored mechanism without changing state or rewards. Motion is
presentation-only and respects reduced motion and hidden-tab pauses.

The melter gains a visible sample-check practice beat after filtration. New
proofs record checked=true; older revision-2 proofs without that optional field
remain replay-compatible. Costs, reward and timing remain unchanged.

Verification: relevant pure engine/replay checks, one final build and a small
visual inspection if available. No broad automated browser campaign or new
dependencies. Do not claim a perfect professional rating or child testing.

## Integrated slice and evidence

All five Day 1 experiments now use the shared illustrated stage and independent
interactive vector equipment. Fine controls, keyboard activation, resettable free
practice and the optional cutaway remain available. Learning statements lead the
layout; expanded notes retain source links and model limitations. Global supply
bars have names/capacities, with spendable Research tokens distinguished from
permanent Research progress. The forecast uses the engine's actual capped result.

passed, including the optional sample-check compatibility case; the production
webpack build passed. No child playtesting or formal professional score claimed.
